# סטודיו מאפים · Bakery Studio

פלטפורמה שמקבלת תמונות של לחמים ומאפים ומחזירה אותן כאילו צולמו בסט צילום מקצועי,
בסגנון שאתם מגדירים: רקע ומשטח, תאורה, אביזרים, זווית מצלמה ואווירה.

## הרצה

```bash
cd bakery-studio
pip install -r requirements.txt
export GEMINI_API_KEY=...      # מומלץ, ראו "מנועים" בהמשך
# ו/או
export OPENAI_API_KEY=...
uvicorn app:app --reload
```

אחר כך פותחים את http://localhost:8000.

## איך זה עובד

1. **העלאה.** גוררים תמונה אחת או כמה. השרת מתקן סיבוב (EXIF) ומקטין תמונות ענק ל-2048px.
2. **סגנון.** בוחרים סגנון מוכן או יוצרים חדש. לכל סגנון יש שדות: משטח/רקע, תאורה,
   אביזרים, מצלמה, אווירה והנחיות נוספות. הם נשמרים ב-`styles.json`.
3. **צילום מחדש.** `prompt.py` מרכיב מהסגנון הנחיה למודל עריכת תמונה. ההנחיה דורשת
   לשמור על המאפה עצמו בדיוק (צורה, חריצים, קרום, מילוי, תוספות) ולשנות רק את הסט,
   התאורה, המצלמה והצבעוניות. אפשר לראות את ההנחיה המלאה בממשק.
4. **תוצאות.** כל תוצאה מוצגת עם סליידר לפני/אחרי ואפשר להוריד אותה. המקור והתוצאה
   נשמרים ב-`data/`, שלא נכנס ל-git.

## מנועים

| מנוע | משתנה סביבה | מה הוא עושה |
| --- | --- | --- |
| Google Gemini | `GEMINI_API_KEY` (מודל: `GEMINI_IMAGE_MODEL`, ברירת מחדל `gemini-2.5-flash-image`) | מצלם מחדש בסט מלא: רקע, אביזרים, תאורה. |
| OpenAI | `OPENAI_API_KEY` (מודל: `OPENAI_IMAGE_MODEL`, ברירת מחדל `gpt-image-1`) | אותו דבר, דרך Images Edit עם `input_fidelity=high`. |
| שיפור מקומי | אין צורך | מאזן לבן, מחמם, מוסיף קונטרסט וחדות ומכהה את השוליים (וינייט). לא מחליף רקע. |

ממשק המשתמש מציג רק מנועים שהוגדר להם מפתח. השיפור המקומי זמין תמיד.

## מבנה

| קובץ | תפקיד |
| --- | --- |
| `app.py` | שרת FastAPI: API לסגנונות, לעיבוד ולהיסטוריה, והגשת הממשק |
| `providers.py` | המנועים: Gemini, OpenAI ושיפור מקומי ב-Pillow |
| `prompt.py` | הרכבת ההנחיה מהסגנון |
| `styles.json` | הסגנונות: כפרי, סקנדינבי, דרמטי כהה, פטיסרי, רקע לבן לקטלוג |
| `static/` | ממשק בעברית (RTL) |

## טיפים לתוצאות טובות

- צלמו את המאפה כשהוא ממלא את רוב הפריים ובפוקוס. המודל משמר מה שהוא רואה.
- שדות הסגנון עובדים טוב יותר באנגלית, אבל עברית עובדת גם.
- אם המודל "ממציא" פרטים, כתבו בהערות: `keep the exact same scoring pattern`.
